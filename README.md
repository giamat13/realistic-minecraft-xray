# Realistic X-Ray (Minecraft resource pack)

X-ray שמתנהג כמו צילום רנטגן אמיתי, ולא כמו x-ray קלאסי שפשוט מעלים בו את כל הבלוקים.

## העיקרון

ברנטגן אמיתי חומר צפוף סופג יותר קרינה, ולכן הוא נראה **בהיר יותר ואטום יותר**. חומר קל כמעט לא נראה.

| צפיפות | בלוקים | מראה |
|---|---|---|
| גבוהה מאוד | ancient debris, netherite, זהב, יהלום, ברזל, אזמרגד | לבן כמעט אטום |
| גבוהה | עפרות (פחם עד זהב) | כתמים בהירים ואטומים בתוך סלע חלש |
| בינונית | stone, deepslate, cobblestone, obsidian | אפור, שקוף למחצה |
| נמוכה | אדמה, חול, חצץ, שלג | אפור כהה, שקוף יותר |
| קלה | עץ | כהה מאוד, כמעט שקוף |
| זניחה | עלים, מים, זכוכית | כמעט בלתי נראה |

הכל שחור-לבן (R=G=B בכל פיקסל). הבהירות היא הצפיפות, והשקיפות (alpha) היא ההחדרה של הקרינה.

## איך זה בנוי

- `assets/minecraft/textures/block/*.png` – הטקסטורות (16x16 RGBA, גווני אפור בלבד), נוצרו ע"י `tools/generate_textures.py`.
- `assets/minecraft/models/block/cube.json` – דורס את מודל הקוביה הבסיסי עם `render_type: translucent`, כדי שהשקיפות החלקית של הטקסטורות תעבוד על כל בלוק-קוביה (stone, ores, dirt וכו').
- `pack.mcmeta` – מטא-דאטה של החבילה.

## התקנה

העתק את התיקייה כולה (או zip שלה, כשהקובץ `pack.mcmeta` בשורש הארכיון) ל-`.minecraft/resourcepacks/` והפעל במסך Resource Packs.

## הגבלות ידועות

- עדיין לא נבדק בתוך המשחק בפועל; ייתכן שיידרש כיוונון של `pack_format` לגרסה שלך.
- בלוקים עם מודל משלהם שאינו יורש מ-`block/cube` (למשל grass_block עם שכבת overlay, עלים עם מודל משלהם) לא מקבלים `translucent` אוטומטית, ויראו חלקית.
- טקסטורות מונפשות (מים, לבה) הוחלפו בפריים בודד.
